# 按需复习与生成补位方案

日期：2026-09-14。状态：讨论原稿，现已实施为主线策略3；最终口径、参数及验证见[实施记录](mainline_strategy_v3_implementation.md)。衔接[逐档推进与指纹方案](2026-09-14-tier-progression-and-fingerprint.md)。

## 1. 已明确的产品意图

- 复习指有意安排的复习，不是所有曾出现过的词。
- 目的是帮助玩家掌握成语，重点关注填错过、提示过的词，不必每关安排。
- 每关主动安排与补位使用的复习词合计0—2个；不是必须填满的配额。
- 可在生成阶段尝试用复习词补足缺口。所有选择在题面展示前完成，局内不改题。
- 普通随机选词允许再次遇到旧词；近期排除和成语集合hash继续负责相邻重复与整组重复。复习上限本身不能保证题目其余词都新鲜。

以下调度细节及数值均为首版建议，不代表已经上线或已验证的最佳参数。

## 2. 当前实现与需要纠正的地方

当前`MainlineLearning.dueWords`只判断到期时间，曝光或完成过的词都有机会到期，并没有要求该词填错或用过提示。生成端会优先抽取“到期词或熟悉词”，不区分复习动机。

当前学习接口已有每局`wrong`词集合及整局提示总数；游戏提示操作也会将当前成语标入错误集合。因此可以利用已有信号识别部分薄弱词，但旧记录不能可靠区分误填与提示，也不能把整局用过一次提示推断为所有词都需要复习。后续记录应保留词级原因；交叉格提供的间接帮助单独视为辅助证据，不自动断言两个词都不会。

当前生成器未凑齐目标词数会直接返回null。因此“差1词就补一个”需要在生成器放弃当前部分布局前尝试补位，不能在外层拿到null后简单追加。此前调查的主要瓶颈是约束与贪心搜索叠加，复习补位只是辅助措施，不能替代剩余配额前瞻与有界回退。

## 3. 哪些词值得主动复习

建议维护轻量的薄弱词队列，复用现有学习记录，不另建复杂学习系统。

| 观察 | 建议处理 |
|---|---|
| 一次误填 | 低优先级候选，后续自然作答正确可消退，不立即认定不会 |
| 针对该词用过提示 | 进入复习候选，保留辅助完成的证据 |
| 不同题中反复填错或依赖提示 | 提高复习优先级，但仍遵守间隔与数量上限 |
| 只是出现在失败题中，尚未尝试 | 不自动入队 |
| 只是日期到期、以前见过，或预填较多 | 不单凭这些条件入队 |

同一局多次误触不等同多次独立失败，不让反复点击把优先级无限抬高。普通抽样中的作答也会更新薄弱状态，不要求必须被标记为复习题才能消除复习需求。

旧数据只迁移有可靠词级薄弱证据的词；无法还原原因的历史记录不虚构提示次数，不把所有旧到期词搬进队列。

## 4. 何时出现、一次几个

建议先采用简单调度：默认不预留复习名额，有合适需求时通常选1个；只有多个需求较明确、且题面负担合适，或补位确有帮助时才考虑第2个。不做固定每几关必出，也不设置到期清债任务。

首版间隔可以这样开始验证：

- 任何主动复习都避开最近3道实际展示的新题，包括失败和换题；恢复同一题不增加间隔计数。这里从目前“近期通关题”扩展到实际展示记录，需与指纹记录一起实现。
- 首次复习建议在距该词上次出现至少隔开6道其他新题，或过去约1天后成为可选；即使时间到期，仍须满足最近3题冷却。这兼顾连续玩与隔日玩的用户。
- 到期只代表可以安排，不保证下一题出现。不合当前档位、难以连接、近期复习负担偏多时可推迟。
- 默认避免连续两题都主动安排复习；生成补位可打破这一软偏好，但不能打破同词冷却和每题2个上限。
- 没有合格复习词时，正常生成0复习词题，不为了“复习功能有存在感”选已掌握词。

这里的6题／1天是待验证的起点。无需首版就引入复杂记忆曲线或多组概率参数。

## 5. 如何逐步退出复习

复习完成不立即等于掌握。一次较可信的无错、无针对性提示完成后，降低优先级、延长间隔，例如下一次候选门槛提高到隔开12道其他新题或约3天，仍满足近期冷却。

建议两次有间隔的较可信成功后退出主动队列；普通随机出现时的成功也计入。预填大量答案或交叉填字直接带出答案只能算较弱证据，不把这种成功当成独立回忆。若又出错／依赖提示，可重新进入队列，但不紧接着追问同一个词。

“退出队列”仅表示暂时不再主动安排，不意味着永久掌握，也不阻止普通抽样遇见。词级掌握证据用于后续档位推进时，应防止少数反复复习词累积大量次数，掩盖整个档位覆盖不足。

## 6. 与普通选词和生成补位结合

建议流程：

1. 先根据逐档推进与平滑规则确定本题词数、档位配额和题面负担。
2. 普通候选正常随机抽样；另筛出已过间隔、属于本题可用档位的薄弱词。主动复习只是选词偏好，不是生成必须完成的任务。
3. 如有合适需求，优先尝试1个复习词；不合适就用普通词。不再对全部到期旧词统一加权。
4. 若部分布局只缺1—2个词，且正常扩展遇阻，在剩余复习名额内查找符合缺口的词，优先只补1个。补入词必须占用本题已有名额，而不是把目标8词题扩成9词题。
5. 优先使用尚未纳入普通抽样池、但符合规则的复习候选，按交叉字位置与剩余档位检索；否则仅给同一批词换上“复习”标签并不会提高成功率。
6. 补位不能完成就撤销该分支，继续既定的有界换词／换布局流程；不能无限重试，也不把未满规模的半成品展示给玩家。

例如目标8词题，已有7词且还缺1个基础词，可以查找过了冷却、适合交叉的基础复习词；找不到就换分支。不能因为有个生僻复习词很好连接，就突破玩家当前的基础／拓展边界。

**复习词不等于熟悉词。** 曾经错过且尚未掌握的词仍可能占用陌生词预算；补位时必须按其实际熟悉度计算，不能靠改标签绕开预算。主动选择与补位合计最多2个；实施时按用户“有意安排”的定义计数：主动选择和备用池补位合计最多2个。普通随机抽中的其他薄弱词单独记录为incidentalWeakWords，作答同样更新学习状态，但不冒充主动安排；所有旧词另行统计。初稿将全部到期薄弱词都计入上限，在整个词池都曾出错时会使6词题无法生成，因此不采用这一额外限制。

以下约束保持：校准后6—12词、阶段档位配额、相邻题平滑、同词近期冷却、候选字干扰比例且至少4个、答案消歧、整组指纹去重、已展示题面冻结。复习选择的软偏好可让位于生成可行性，这些硬边界不能让位。

## 7. 减少重复感与验证

有意复习时更换搭配，优先避免总把同一词放在同一组词里；hash只排除完全相同集合，不保证部分重复消失。此版不额外增加近期20题重合硬限制。

记录主动复习词及选择原因（学习安排／生成补位／普通抽中合格薄弱词），并分别统计：主动复习数量、所有旧词数量、单词曝光集中度。不能以“每题复习只有1个”掩盖普通抽样反复出现大量旧词。

验证重点：

- 无薄弱记录时不为填名额安排复习；一次提示不把全题标成不会。
- 复习冷却、0—2上限、档位和题面约束均无违规；恢复同题不重复计数；每日挑战行为保持兼容。
- 间隔后的自然成功能降低复习需求，退出队列后不继续追问；重复失败不会造成连续同词轰炸。
- 对相同玩家状态、相同约束做有无补位的对照，报告单次请求失败率、补位挽救数及耗时，包含无可用复习词的冷启动；不能预先承诺补位一定提高成功率。
- 同时观察普通旧词重复与薄弱词后续表现，防止成功率提高却让玩家总遇到卡住的词。

建议首版以轻量队列、0—1常态／2上限、间隔后可选、有界补位为主。先验证这些规则，再决定是否需要更精细的调度；对应代码及验证已进入策略3实施记录。
