# 四档词汇分级与全智能主线：执行计划

日期：2026-09-11  
状态：用户已批准实施；P0—P4及P5本地验证完成，真机与真人试玩待验收。实现、参数及限制见[验收记录](four_tier_implementation_v2.md)。

目标：把教材审核结果落实为全库四档分级，取消手动主线难度选择，按玩家表现生成适合的后续关卡。

## 1. 决策依据与适用范围

本计划汇总本轮已确认的讨论，实施时优先于[2026-09-09改造方案](2026-09-09-difficulty-and-level-experience-redesign.md)中冲突的内容。[首版实现记录](mainline_implementation_v1.md)仅代表历史实现，不代表本轮完成状态。

本轮明确替换：

- 固定465条主线准入限制，以及“未审核不能参与主线”的做法。
- 用户手动选择“轻松入门／日常挑战／成语高手”。
- 用关卡号、科举等级或旧1—50分线性推高词汇难度的主线逻辑。
- 按词数倍数、最少2个计算干扰字的旧规则。

继续保留：交叉布局、重复答案字的数量约束、答案消歧、主动提示道具、失败后的换题、奖励防重、关卡冻结与断点恢复。

不增加局内换题入口，不自动在局内增加线索或减少候选字。旧 `difficulty-manual-change.md` 仍只参考第4部分的5条拼音修正，其余旧分级意见不重新启用。

本轮主线适配是重点。每日挑战不改为个人自适应玩法；词库扩充带来的每日选词、版本兼容影响必须处理，不能仅因入口代码未改就声称每日题目不变。

## 2. 已确认的产品规则

### 2.1 四档词汇等级

每条四字成语具有唯一全局等级：**入门、基础、拓展、生僻**。

| 依据 | 默认等级 |
|---|---|
| 本次审核表明确标注难度 | 使用人工标注 |
| 最早出现于小学1—2年级 | 入门 |
| 最早出现于小学3—6年级或初中 | 基础 |
| 最早出现于高中 | 拓展 |
| 教材未覆盖、旧465条已覆盖 | 沿用旧清单等级，入门优先于其所属基础集合 |
| 其余数据库词条 | 根据旧分及统计关系快速推断，并记录推断来源 |

优先级：**本次人工难度标注 ＞ 教材默认分档 ＞ 当前旧清单 ＞ 旧分推断**。

- “教材”指本批已审核提取结果，不把新的自动命中未经确认地冒充教材审核结论。
- 按本批教材的最早册次处理；高中册次不强行对应高一／高二／高三。
- 即便旧分很高，“蒙袂辑屦”“矞矞皇皇”等仍按教材分档，除非用户明确指定例外。
- 全局分档与个人熟悉程度分开。玩家不认识某条基础词，不自动更改其全局等级。
- 旧 `intro` 是 `foundation` 子集；新数据库等级互斥。生成时可组合“入门＋基础”等集合，不能再重复存两档。

### 2.2 保留、审核与选词资格

- [有数据库ID审核表](../reviews/textbook-idioms/有数据库ID_四字成语审核表.md)内全部词默认保留，空白难度按教材规则。
- [无数据库ID审核表](../reviews/textbook-idioms/无数据库ID_四字候选审核表.md)只接纳明确“保留”的四字词，其余不入库。工作区文件名仍带“候选”二字，以此真实路径为准。
- 用户已确认“漫天风雪”的“成语”标注是笔误，按“保留”处理；导入时专项纠正，不把所有未知标注都自动解释为保留。
- 教材保留词及原465条均记为已审核，重叠部分只记一次。原始OCR候选全集不算已审核成语。
- 审核状态只用于记录和避免重复审核，**不得成为关卡生成的过滤条件或隐藏降权条件**。
- 所有最终入库词都参与主线选词。自动推断为入门的词也能进入入门配置。
- 全词库参与不等于均匀抽样、不等于每个玩家每个阶段四档概率相同，也不要求玩家最终做遍全部词。
- 此处“保留”是词条有效，不代表重新审核已有数据库所有成语，也不等于统一放入基础档。

### 2.3 全智能适配与题目冻结

- 移除三档手动难度设置，不用年龄、学历或科举等级替代玩家能力判断。
- 系统结合整体表现、各档表现和具体成语熟悉程度，确定下一道新题。
- 初始阶段先提供易理解、规模小的题，逐步观察。智能适配以缓慢、平滑、尽量不被玩家察觉为原则；即便判定玩家熟练或吃力，也只通过后续多题逐步过渡，不快速跳档。
- 题目生成后，成语、布局、预填字、候选盘及策略参数冻结；进入局内后不自动调整难度。
- 主动提示／清空等既有玩家操作照常生效；它们不属于自动改题。
- 退出恢复和原题重玩保留原题配置；失败后确认换题属于新生成，可采用更新后的能力估计。
- 适配不把后台停留、普通中断或用时偏长直接视为不认识成语。
- 预填3字后填对1字不是强掌握证据；多线索、交叉支持及使用提示下的完成应区别于独立回忆。

### 2.4 主线词数范围

- 水平校准阶段可使用少于6个成语的小棋盘；首版暂按第1—10关安排，具体逐关词数在实施中校准。
- **校准阶段之后，每关实际成语数下限6个、上限12个**；按上述首版安排，从第11关开始执行。
- 6—12是最终题目的硬边界，不只是生成器的目标词数。自动适配只能在该范围内调整，不能因玩家吃力而生成不足6词的普通关卡。
- 减负优先降低词汇跨度、增加生成时的预填支持或调整干扰系数；局内仍保持冻结。
- 布局失败可重试、替换候选成语或在6—12内减少目标词数；6词仍生成失败时明确返回生成失败，不以2—5词题目兜底。失败后换题同样遵守当前阶段范围。
- 校准阶段按主线关卡号识别，不因换题次数反复重置；玩家退出恢复、重玩旧题仍遵守原题冻结兼容规则。

### 2.5 候选盘

令 `A` 为实际待填格对应的答案字份数：同一交叉格只计一次，不同格所需的重复字分别计数。

```text
D = max(4, ceil(A × r))
候选总数 = A + D
```

- `D` 是干扰字数；`r` 是相对待填答案份数的干扰系数，不是干扰字占整个候选盘的比例。
- `r` 在生成新题时由策略确定；局内冻结。
- 干扰字至少4个，每行最多10字，末行不补齐；不回到固定40格。
- 消歧导致预填字增加时，应先完成题面消歧，再计算最终 `A`、`D`，避免干扰比例失真。
- 保留现有形近／音近干扰及消歧约束。替换被排除的干扰字，而不是削减到低于预算。
- 如果合法干扰字不足，先扩充合法候选或重新生成题目；不得通过放回歧义字或静默少放干扰字满足流程。
- 允许的倒装／等价答案沿用已有规则。现有有限重试不等于数学意义上的无歧义证明，需验收最终结果和回退路径。

## 4. 数据落地方案

### 4.1 建立唯一可复现的分级来源

新增导入／分级脚本，读取审核表、旧清单和数据库，生成统一的版本化分级清单、统计与冲突报告。字段名称可随现有工程约定调整，但职责不变。

建议数据库字段：

| 字段 | 职责 |
|---|---|
| `difficulty_tier` | 唯一四档等级 |
| `difficulty_source` | 人工指定／教材默认／旧清单／旧分推断 |
| `difficulty_version` | 分级版本及迁移追踪 |
| `is_reviewed` | 审核记录，选词逻辑不读取它作为准入条件 |
| `difficulty`（保留原字段） | 旧1—50分，兼容及分析用途 |

精确教材出处、人工覆盖、源文件哈希与映射参数放在统一内容清单／证据文件中，以稳定ID关联。不要维护数据库、manifest和旧主线JSON三份互相独立的人工分级。

原提取manifest保留为历史证据；`mainline_content.json` 中旧词池转为迁移输入或派生产物。其5条拼音修正不能因迁移清理而丢失。

### 4.2 新增词与旧ID

- 222条新词分配未使用的稳定ID，已有ID不因拼音、排序、分档而变化。
- 补齐拼音、缩写、解释、首尾字等现有必填字段，核验规范写法与数据来源；这属于数据完整性检查，不重新否决用户已确认的保留结论。
- 同步原始数据、评分／构建输入、稳定ID映射、资产库及字符索引，按实际依赖处理新增词的旧分兼容值，并标记其为兼容估值。
- 新词没有旧分，不参与“旧分预测新档”的训练统计；其四档直接取人工／教材依据。
- 对异体、倒装及规范词关系做兼容检查，不擅自合并已确认的独立词条。

### 4.3 快速推断与映射报告

1. 固化上述人工、教材、旧清单锚点，推断程序不得覆盖。
2. 输出旧1—50每分及分段的锚点分布、分位数、交叉表和两类例外。
3. 评估简单可解释的连续区间方案；分别报告前三档区分能力与生僻尾部分界的假设，不能把后者描述为已训练得到的结论。
4. 对数套相邻边界进行敏感性分析，展示剩余26,669条和最终全库的分档数量、边界词样本与预计生僻占比。
5. 在报告中选择并固化一套首版参数，生成全库暂定等级，标记 `difficulty_source=旧分推断`。不强制按80%—90%比例切词。
6. 未审核词照常选入；后续用户可抽样纠正，重跑时人工覆盖优先，历史审核记录不丢失。

具体旧分区间尚未在讨论中确定，不能把示例区间写成用户已确认结论。首版采取快速推断，不把新增大规模人工审核或训练复杂模型作为开工前置条件。

## 5. 全智能生成方案

### 5.1 能力估计与具体成语记忆

在现有 `mainline_learning.dart` 基础上迭代，区分：

- 整体和各词档的完成表现，用来制定下一题的词汇组合。
- 具体成语的曝光、辅助完成、独立完成、延迟回忆与复习需求。
- 题面支持程度、错误、提示和有效用时，用来解释表现，而不是只看输赢。

先实现可解释、有界的规则策略；每次变化可追溯到观察记录。初始能力不要由旧三档设置、科举经验或总通关数直接赋值。

取消现有偏好设置UI；旧设置可保留作历史兼容，但不能继续控制新题。旧学习记录能可靠复用的部分继续用，缺少策略／支持信息的记录采用保守权重，不一次性把老玩家推到高难度。

### 5.2 初期校准与后续调整

水平校准阶段首版暂按第1—10关安排；之后每关6—12词的边界已经确定。以下节奏是待校准的工程起点，不是新的固定关卡难度曲线：

- 前1—3道新题以小棋盘和适量预填字帮助建立操作体验。
- 第4—10道题逐步观察独立完成与提示依赖；校准阶段也遵守小步调整，不因少量样本快速升降。校准后必须达到6词下限，因此校准末段应逐步接近6词，避免第10／11关突然从小棋盘跳到大棋盘；必要时通过生成时的词汇和预填支持保持平缓。
- 综合近期多题趋势并平滑更新能力估计；一次失败、换题或一次无错误完成不能单独触发明显升降。连续受挫可以启动后续小幅减负，但不能一步切换成显著更简单的题。
- 每次策略调整优先只改变一类挑战：词汇组合、词数／待填量、预填支持、干扰系数；不要同时升高或降低多个维度，避免总难度突变。
- 多词都困难时降低词汇跨度；只卡一词时调整后续该词的练习支持，不武断降低整体能力。
- 不设置局内自动救助。所有自动策略调整只能作用于之后新生成的题。

平滑控制必须落实到最终题目，而不只限制内部能力分数：

- 使用多题观察、平滑估计、小幅步长和调整间隔；不是每关都必须改变参数。具体窗口、步长和间隔在轨迹验证后固化。
- 升高与降低采用有间隔的触发边界，避免表现落在临界点时反复升降；调整后保留观察期，不因下一题的偶然表现立刻反向调整。
- 为词数、待填量、低熟悉词预算、预填支持和干扰系数设置单次变化上限。词数由6逐步增加至12，不能直接跳变；具体步长在实施中确定。
- 干扰字按最终待填量计算，因此词数或预填字变化可能连带改变候选总量；必须一并检查，不能只看干扰系数是否保持不变。
- 检查最终生成结果相对近期题目的复杂度变化，防止随机抽到多条陌生词、布局变化或生成回退绕过平滑约束。
- 生成失败时先重新选词／布局；如果减小规模会造成明显跳变，应返回生成失败，不用骤降规模来掩盖失败。仍同时遵守校准后6—12词范围。
- 页面不显示“系统已升难度／降难度”等打断提示，也不恢复手动难度档位选择；内部记录调整原因用于调试和验证。


必须防止同一题的失败、复活、换题或重复进入被累计成多次独立能力观察；时间顺序和终态更新规则要明确。当前已结束题的有效表现应被后续新题使用，取消换题不能凭空产生一次换题观察。

### 5.3 选词与配额

生成顺序：

1. 读取个人状态，生成本题策略快照：四档目标配额、个人低熟悉词预算、复习需求、规模、预填支持与干扰系数。
2. 先确定档位配额，再从档内全量词中选取，结合个人记忆、近期重复排除与交叉可布局性。
3. 生成交叉布局后检查最终实际配额；候选池比例不能替代题目配额。
4. 用现有消歧逻辑确定最终预填字，再按最终待填量生成候选盘并检查干扰字数量与歧义。
5. 冻结题目、候选盘和策略，进入游戏。

- 不按词库各档数量比例直接抽样，防止生僻因数量庞大而占据主线。
- 不对所有玩家永久锁死生僻档，也不因关数增加而最终切换成纯生僻题。
- 生僻或个人陌生词可以在生成时给予更多支持，复习时逐步减少支持；不是局内临时送字。
- 已审核和未审核词使用同一套档内选词逻辑。
- 全局等级不等于个人是否熟悉；基础词也可能需要支持，生僻词也可能已被该玩家掌握。
- 生成困难时优先调整布局、扩大相同档位的抽样候选，或在当前阶段词数范围内减小规模；校准后不得低于6词或超过12词，不得静默突破本题难度边界、干扰下限或冻结规则。
- 不直接照搬旧“拓展每关最多1条”作为永久全局规则；新配额由个人策略确定。

## 6. 兼容与迁移

- 新增数据库字段和222条新词通过版本化、事务、幂等迁移写入；验证ID、行数、索引及回滚，保留进度、收藏、历史、学习数据。
- 全库四档必须完整，旧分继续保留；数据构建与旧安装迁移必须得出相同内容结果。
- 保存新策略版本、内容版本、四档配额、支持程度、干扰系数及题目实例，便于复现适配决策。
- 老存档继续恢复原题与候选盘，不强行套用“至少4个干扰字”等新规则；新规则只用于新版本新生成的题。
- 失败后的“换一道题”保留同关号，不发通关奖励；无局内换题按钮。确认弹框保持主题风格、简短文案及“取消／确认”按钮。
- 每日挑战保持原玩法和限时规则。建议版本化其候选词集合／生成种子策略，避免当天跨版本题目被新词插入无意改变；实施时验证并记录兼容边界，不承诺未经验证的全版本同题。
- 分享／导入题目涉及新增ID或新策略字段时，验证缺省行为与不支持版本的处理；不能错配已有ID。

## 7. 实施顺序与验收

| 阶段 | 工作内容 | 验收产物／条件 |
|---|---|---|
| P0 审核结果固化 | 导入两张表，纠正“漫天风雪”，整合旧465条，生成来源与例外清单 | 教材2898条、已审核并集3055条与差异报告；不重复审核、不改教材结论 |
| P1 全库分级 | 输出旧分统计、映射候选与敏感性分析，固化首版推断参数 | 每条词有唯一四档；人工优先；来源及参数可追溯；推断样本与各档数量可检查 |
| P2 内容及数据库 | 新增222条完整数据、稳定ID、新字段、字符索引与迁移 | 预计29,724条全部四字；已有ID完全不变；新安装与升级一致、迁移可重入和回滚 |
| P3 个人状态 | 迭代学习记录和自动能力估计，移除手动三档设置及其控制逻辑 | 冷启动、熟练、受挫、中断、复活和复习轨迹可解释；审核状态不参与选词限制 |
| P4 生成与候选盘 | 全库分档采样、最终配额、题面冻结、比例干扰盘、消歧复用 | 最终难度约束成立；校准后实际6—12词；`D≥4`且满足比例；局内不自动变化；失败换题与恢复正确 |
| P5 集成与体验 | 模拟玩家轨迹、关卡抽样、全量回归及真机升级 | 对比前10／20／200关与长期样本，记录参数依据、性能及兼容结果 |

P0→P1→P2先建立稳定内容基础；随后推进P3、P4，再做P5。不得只完成分级文件就宣称全智能关卡完成，也不得只移除设置入口而继续偷偷使用旧偏好。

### 必须覆盖的验证

**数据与迁移**

- 标注解析、四字过滤、222条接纳、现有词默认保留、手工覆盖及教材优先。
- 旧清单子集去重、165条冲突、两类例外、重复生成不会覆盖人工结论。
- 全库等级覆盖、新旧ID映射、拼音与解释字段、字符索引、迁移幂等及回滚。

**算法与状态**

- 审核标记不同但档位相同的词都可进入候选；抽样结果不因审核来源产生准入差异。
- 生僻档在适合的策略中可被选入；全库大量生僻不自动抬高其关内配额。
- 弱基础、熟练、某档薄弱、偶然失误、频繁提示、后台中断、辅助完成与延迟回忆的轨迹测试。
- 一题事件不重复增加能力证据；新题响应有效的新状态，原题重玩和恢复不改配置。
- 最终配额、布局可解性、重复答案份数、比例及4个干扰下限、合法干扰不足回退、消歧与允许替代答案。
- 校准阶段边界（首版第10／11关）、普通关卡6词下限与12词上限；受挫减负、稀疏候选、布局失败和失败换题都不能突破词数边界。
- 连续成功、连续失败、成功失败交替、临界表现及能力长期变化的轨迹：验证小步过渡、调整间隔、防反复升降，以及校准末段到普通关卡的平滑衔接。
- 对相邻新题的实际词数、待填量、干扰总量和个人低熟悉词数量检查变化幅度，避免随机布局或回退引发突变。
- 12词棋盘及相应候选量的小屏布局、操作区域与生成性能。

**界面与回归**

- 三档设置入口移除，原设置不再影响生成；局内无自动送字、无自动缩盘、无换题入口。
- 失败换题弹框主题、文案、取消／确认、进度和奖励防重。
- 小屏候选盘、末行布局、输入、提示、恢复及新旧存档兼容。
- 对现有每日挑战、分享／导入、成长与收藏运行相应用例；失败项区分新增回归与已确认基线问题。
- 对适配后规模与提示变化造成的经验获取节奏做观察；未经讨论不改奖励公式。

代码与模拟测试不能证明留存改善或教材等级等于所有人的实际难度。验收先证明规则与迁移正确，再用试玩和后续抽样校准参数。

## 8. 尚待实施阶段确定的数值参数

以下方向已确定，具体数值尚未在讨论中拍板；实施时应配置化、给出样本和依据，不能声称已经过用户或实测验证：

| 参数 | 已确定约束 | 落地方式 |
|---|---|---|
| 旧1—50分映射边界 | 仅推断无直接依据词；不覆盖锚点；不强凑生僻比例 | P1比较候选，固化首版估值及版本 |
| 干扰系数 `r` 的范围和步长 | 按待填量比例；最少4个；局内冻结 | P4按棋盘样本和玩家轨迹校准 |
| 校准节奏、观察窗口、平滑强度、调整步长／间隔与升降边界 | 首版暂按第1—10关校准；之后实际6—12词；多题缓慢过渡，防止反复升降；不以单次用时定能力；只改新题 | P3/P4验证能力轨迹与最终题面相邻变化 |
| 各档配额、陌生词预算、生僻首次出现条件 | 全词库参与；不按库存占比抽；不随关数无限升级 | P4按个人状态配置并检查最终题目 |
| 每日题目跨版本策略 | 原玩法保留，词库扩充影响须显式处理 | P2/P5选择并验证内容版本兼容办法 |

这些参数的首版选择属于计划内的实施与校准工作，不要求用户先完成额外全库审核。若实施需要改变本文件第2节的已确认产品规则，应明确提出差异再讨论。
