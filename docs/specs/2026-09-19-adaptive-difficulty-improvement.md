# 动态难度改进方案：覆盖率、用时与渐进回退

日期：2026-09-19。

状态：已按本次会话实施为主线策略4。下文保留问题背景与规则说明，第10节记录实施时补齐的参数；自动化验证见第11节。参数仍需真实试玩校准。

## 1. 背景与目标

玩家反馈：前期通关顺利，到第128关已遇到一些拓展词，体感偏难。尚未读取该玩家存档，不能据此断定其当前词汇阶段、step或具体升级轨迹。

改动前的策略3有以下问题：

- step控制题面，tier控制词汇，两者独立；至少5次有效观察才可能调整step，不是每5关必升，也不是150关后才进入下一词汇阶段。
- 词汇阶段使用6／24／36个不同词等固定证据门槛，少量成功可能过早推动整档试探。
- 用时已记录，但未参与难度判断；花更久才能完成，仍可能被视为适合升级。
- 词汇回退通常要等趋势低于0.5，容易停在“能完成但已经吃力”的状态。
- 生僻阶段每题仅保留1个低档词名额，其他名额都是生僻词，低档内容出现过少。

改进目标：覆盖率决定是否有资格试探，近期表现决定实际试探量；升级更稳，受挫及时减负；到达高档后仍长期混合低档词。

范围为普通主线动态难度。此次不调整成语人工分档、每日挑战规则、奖励规则，也不因总关号自动提高词汇难度。

## 2. 核心概念与证据口径

| 概念 | 用途 |
|---|---|
| 题面step | 控制成语数量、待填字数、干扰字等题面负担 |
| 词汇阶段tier | 表示当前学习阶段及允许接触的相邻高一档 |
| 累计有效覆盖率 | 控制下一档的准入资格和比例上限 |
| 近期表现 | 控制是否增加、保持或回退实际难度 |
| 有效结算 | 新题实例的通关、失败或换题结算；同一实例不重复计入能力证据 |

累计覆盖率不因减负而清零，也不能阻止减负。历史表现不能代替近期表现。

词级有效成功记录要求：该词完成、该词没有错误或提示、预填不超过两字。同一词重复成功不重复增加覆盖数。这是题面支持下的有效成功证据，不等同于无提示背诵掌握。

提示按词归属判断，避免对其他词使用提示就取消整局所有词的证据。历史记录无法区分提示归属时不虚构词级证据，旧存档提示归属缺失且已用提示时，保守不增加该局词级覆盖；无提示旧局仍可提供证据。

用时暂不取消词级成功记录，只影响近期升级和减负判断，避免一次挂机损失整局覆盖记录。

## 3. 用时参与难度判断

### 3.1 统计口径

- 沿用有效用时：当前代码会排除切后台和离开游戏页的时间，前台挂机仍可能计入。
- 单局单位耗时＝有效用时÷初始待填字数。初始待填字数按冻结题面统计，不使用提示后的剩余字数。
- 取最近5局已完成新题，去掉单位耗时最长的一局，对剩余4局取算术平均。
- 比较基准为此前最多20局同一主体档位的单位耗时中位数，基准样本不与近期5局重叠。
- 同档基准不足10局或近期有效计时样本不足5局时，暂不使用时间信号，继续使用其他表现证据。
- 失败和换题不参与完成速度平均，另行计入受挫判断；不能因提前退出、耗时短而被视为轻松。
- 缺失或无效计时不按零秒参与统计。
- 进入试探或减负观察期时固定比较基准，避免持续变慢被滚动基准逐渐吸收。

### 3.2 首版阈值

设R＝近期平均单位耗时÷个人基准单位耗时。

| 条件 | 行为 |
|---|---|
| R≤1.2 | 时间方面允许升级，仍须满足其他条件 |
| R>1.2 | 暂停升级 |
| R>1.5，连续两次评估成立 | 触发一次减负 |

两次评估应由不同的新题结算触发，重复保存不产生新评估。单局慢不直接触发降难。

去掉最长一局只能抵抗单次异常，多次前台挂机仍可能影响结果。按待填字数归一化也不能完全消除布局、陌生词比例的影响，需在试玩中检查误判。

## 4. 累计覆盖率与下一档准入

有效覆盖率＝本档有有效成功记录的不同成语数÷当前内容版本中本档成语总数。

分母不是已见词数，也不是单次生成候选池大小。词库版本及分档变化时应按词条身份重新归属证据，并记录所用内容版本，不能把内容变化误判为玩家退步。

本次确认：在最初建议的10%／20%／30%／40%基础上，所有覆盖门槛提高10个百分点。

| 当前档位有效覆盖率 | 下一档比例上限或权限 |
|---|---|
| <20% | 不引入下一档 |
| ≥20%且<30% | 上限20%，首次只试探1个词 |
| ≥30%且<40% | 上限35% |
| ≥40%且<50% | 上限50% |
| ≥50% | 允许逐步交接到下一阶段的混合配比 |

上限不是自动配置目标。达到覆盖率后仍须检查近期表现，只能接触相邻高一档，不越档。

按实施时的内容版本6计算（四档数量与版本5一致），首次准入要求向上取整：

| 当前档位 | 总词数 | 20%有效覆盖所需不同词数 |
|---|---:|---:|
| 入门 | 475 | 95 |
| 基础 | 3661 | 733 |
| 拓展 | 4140 | 828 |
| 生僻 | 21448 | 没有下一档，不设置继续升档门槛 |

这会显著放慢基础到拓展的推进，储备丰富的玩家也需积累更多记录。这是本次接受的取舍，但应验证重复感及长期推进速度。

## 5. 试探幅度与升级节奏

- 首次试探只增加1个相邻高档词。
- 每次调整最多增加1个高档词名额，不同时提高词汇和题面负担。
- 两次词汇加难至少间隔10次有效结算。
- 最近10次有效结算至少8次顺利完成。
- 已开始试探后，增加下一档比例还要求下一档词近期有效成功率达到85%。首次尚无下一档数据时，不能要求先有该档成功率才能开始试探。
- 时间信号可用时，不能存在明显变慢；时间数据不足不伪造速度评价。
- 减负观察期内禁止升级；覆盖率达标不能绕过观察期。

“顺利完成”指成功通关、不使用提示、错误至多1次。下一档成功率取近期10次结算中最近5次有该档曝光的结算，按有效成功词数／曝光词数计算；至少5次曝光结算才能使用。未完成或过多预填不提供有效成功证据，不能用单个试探词的一次成功立即继续加量。

题面step继续与词汇阶段分开，实施时也将上调间隔统一为至少10次有效结算；时间、近期顺利率和受挫信号共同拦截上调。存在足够词级样本的档位，近期有效成功率还须达到85%，避免词汇已经吃力却继续增加题面负担。

## 6. 更及时的主动减负

不再仅依赖趋势低于0.5。以下任一条件可触发一次减负：

| 近期信号 | 首版触发条件 |
|---|---|
| 失败或换题 | 最近3次有效结算中有2次 |
| 提示或较多错误 | 最近5局中有3局使用提示或出现至少2次错误 |
| 持续变慢 | R>1.5且连续两次评估成立 |
| 下一档词表现吃力 | 最近5次有下一档词曝光的结算中，该档词有效成功率低于70% |

同一结算同时满足多个条件，只执行一次减负，不叠加惩罚。

回退处理顺序：

1. 有下一档试探词时，优先减少1个试探词。
2. 没有试探词、但当前档词汇明显吃力时，用低一档替换1个当前档词，逐步回撤。
3. 词汇表现稳定、主要是题量负担时，降低待填量或干扰字。

只出现整体变慢时不能断言一定是词汇问题，实施时需结合词级错误和提示决定减负维度。

减负后至少观察3次新结算再考虑继续减负，至少10次再考虑升级。旧受挫窗口不能未经新证据反复触发；累计覆盖记录保留。

当前部分相邻step的预算完全相同，因此题面减负应移动到下一个实际减少待填量或干扰字的预算档位，而不是只把step减1却没有可感知变化。

## 7. 高阶段仍长期混合低档词

### 7.1 改动前的问题

策略3的生僻主体阶段，每题只有1个低档词名额：每5关中1次入门、1次基础、3次拓展，其余词都是生僻词。

以每题10词、连续5关为例，入门／基础／拓展／生僻约占2%／2%／6%／90%。这使常用词在后期过少。

### 7.2 本次确认的调整

达到生僻阶段表示四档都已开放，不表示后续几乎全部选生僻词。生僻阶段稳定后的首版目标配比为：

| 档位 | 目标占比 |
|---|---:|
| 入门 | 10% |
| 基础 | 20% |
| 拓展 | 30% |
| 生僻 | 40% |

按连续若干关累计配额实现，不要求每关机械凑齐。生僻词保持单档最多，受挫时可把其部分配额让给低档。

“覆盖率≥50%允许交接主体”改为交接到下一阶段的混合配比，不沿用旧逻辑中只保留1个低档词的安排。基础稳定阶段采用入门20%／基础80%；拓展稳定阶段采用入门10%／基础30%／拓展60%。

覆盖率表给的是下一档探索上限，不要求探索一定达到上限。对拓展到生僻的过渡，不应为了满足50%这一上限先把生僻堆到50%，然后又降到稳定目标40%；实施时应同时受阶段混合目标约束。

## 8. 10000关及以后

当前普通主线没有“10000关后自动从全区间选词”的分支。普通新关会优先进入动态主线生成器，按个人档位配额读取词库，第10001关同样如此。

旧globalRange相关代码仍存在，但普通主线默认生成入口优先返回动态主线结果，不能靠该参数绕过词汇阶段。已冻结的旧题仍可能保留原生成结果。

新规则继续保持：关号表示进度，不自动解锁档位；所有档位开放后也按混合配比抽取，而非全库无差别随机。

## 9. 已有玩家迁移

- 保留历史覆盖证据及正在作答的冻结题面，不在局内改变难度。
- 不因未达到新覆盖门槛就突然重置到入门。
- 升级策略后进入观察期，暂停继续加难，根据新规则逐步收回不适合的高档词。
- 缺失计时不视为零耗时；旧证据不满足新口径时不能虚构补齐。
- 历史覆盖高的玩家也允许回退，不以既有阶段锁死其难度。

迁移先观察10次结算，期间允许受挫减负但不加难；随后以至少3次结算为间隔，每次最多转移约1个词的配额，逐步把旧的高档密集配比调整为当前阶段的混合目标。只承接旧progression.evidence中的逐词有效名单，不把supported计数直接当作有效覆盖。

## 10. 实施时补齐的细节

以下选择按用户授权自主补齐，均为首版参数：

1. 稳定混合目标依次为100%；20%／80%；10%／30%／60%；10%／20%／30%／40%。达到50%覆盖且配比逐步达到下一阶段目标后，才更新阶段标记。
2. 配比用比例保存，每次最多转移1／本题词数（普通题至少6词）的份额；按连续10次实际曝光分摊整数配额，换题也推进曝光次序，不以关号取整。每题总词数不变，短期单题比例允许整数舍入，累计比例接近目标。
3. 下一档目标同时受覆盖率上限与下一阶段稳定目标约束；超出探索上限的份额暂留当前档。首次直接从当前档转移1词份额到相邻高档，后续逐步调整低档混合结构。
4. 结算窗口只保留最近10次新实例结算。失败／换题计入受挫但不参与完成速度；多个受挫条件只触发一次动作。动作后清空本轮表现窗口，至少3次新结算再减负、10次再加难。停止升级期间继续观察，不按固定关号切换。
5. 当前档词汇吃力的判断取最近3次该档曝光的有效成功率，低于70%时优先回退词汇；有试探词时先减试探。没有这类词汇证据时降低题面预算，并跳过没有预算变化的step。
6. 最近5局时间去掉最长一局，比较此前最多20局同档中位数。首次至少15个有效时间样本才启用。试探、回退及持续变慢期间固定基准；同档稳定、连续10次顺利且速度恢复到1.2倍以内时允许重新取基准。跨阶段重新建立比较基准，不用旧阶段题面给新阶段计时。
7. 调整后时间型再次减负需先积累至少5个新的有效时间评估，再满足连续两次超1.5倍，避免旧慢局在滑动窗口内被重复惩罚。无效或缺失计时不补0。
8. 提示记录所有包含被提示格的成语（包括交叉词），独立保存于断点状态；旧提示归属不明时保守处理，不虚构逐词信息。
9. 学习记录新增adaptiveV4，内容版本改变时从实际数据库重新计算分母及覆盖归属；结算也按当前数据库档位归属词级证据。原来的词级学习、复习记录和实例去重继续保留。
10. 新主线生成策略版本为4，解码接受版本0—4，未来未知版本仍拒绝。旧题定义及题面可直接恢复；已有策略4学习状态时，旧冻结题的首次结算也使用新评估器。未初始化策略4的纯旧实例仍保留旧兼容结算，下一次新主线生成会迁移。

## 11. 验证与验收计划

规则测试：

- 20%／30%／40%／50%边界准确，重复词不增加覆盖，按全档词数计算分母。
- 覆盖率达标但近期吃力不升级；只能试探相邻档，每次变化幅度受限。
- 单次挂机不会直接降难，持续变慢能停止升级并触发减负；计时缺失、样本不足正确跳过时间判断。
- 失败、换题、提示和错误可及时触发回退；同一实例不重复计数，多信号不叠加。
- 回退间隔、恢复升级间隔有效，旧窗口不能无限重复触发。
- 题面减负实际减少预算，词汇与题面不在同次一起加难。
- 生僻稳定阶段累计配比接近10%／20%／30%／40%，低档不会长期消失。
- 10000关前后无词库范围突变，旧存档可恢复，升级不突然重置阶段。

轨迹验证覆盖持续顺利、普通稳定、先强后弱、慢速但准确、偶发挂机、反复失败与换题、高覆盖但近期受挫，以及已有高阶段玩家升级。

连续生成验证检查档位与比例约束下的生成成功率、近期重复感、复习安排及题面平滑，不能靠越档或突破配额兜底。

最后以真实试玩检查“能过但累”的状态能否被识别，以及提高覆盖率后是否出现过长停留或重复感。上述参数在通过验证前仍属于首版调参起点。

### 本次自动化验证结果（2026-09-19）

- `flutter analyze --no-pub`：无问题。
- `flutter test --no-pub`：最终全量325项通过。
- 新增规则测试11项，覆盖覆盖率边界、去重、改档归属、提示归属、探索上限、时间异常、连续受挫、旧状态迁移等。
- 新增真实数据库集成测试6项：1项验证实际分母、结算幂等、提示证据和冻结题面；1条70题不固定阶段的动态轨迹验证先顺利后持续变慢的回退；4个阶段各连续40题验证跨10000关、配额、低档出场、近期冷却与题面平滑。上述连续轨迹共230题全部生成成功，未用重试跳过失败样本。
- 纯规则长轨迹验证490次顺利结算可按已有覆盖逐档交接，随后150次受挫能逐步回退；每次配额份额变化不超过一个词的预算。
- `git diff --check`及本文本地引用检查通过。

以上是本地自动化结果，不代替真实手机试玩。前台多次挂机、单字耗时对布局复杂度的近似，以及提高覆盖门槛后的长期重复感仍需体验校准；没有修改玩家真实存档，也没有执行发布。
