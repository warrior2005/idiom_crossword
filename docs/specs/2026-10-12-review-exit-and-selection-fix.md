# 错词复习退出与候选选择修复

> 2026-10-15已进一步取消复习退出的预填字数限制，并移除熟悉词选词偏好。本文保留10月12日修复时的历史口径，当前规则见[策略5修复记录](2026-10-15-word-selection-fix.md)。

日期：2026-10-12。状态：已实施，验证结果见下文。

## 问题与决定

测试反馈：同一个填错过的词在靠近的关卡反复出现。定向模拟中，固定入门6词，目标词每次误填后完成、其他词正确，“深更半夜”在第1、8、15、22、29、36题出现，后5次均为主动复习。

检查发现：累计错误次数会提高复习候选优先级；退出复习又要求整局无提示、该词最多1个待填交叉格。目标词本身正确，但其他词使用提示，也不能累计退出成功次数。

按用户确认，本次修复两处：取消上述退出限制，去除累计错误次数对复习选择的加权。

## 当前规则

- 退出成功证据按词计算：本词已完成、本词没有错误、本词没有接受提示、预填不超过2字。
- 不限制待填交叉格数量，其他词的提示和错误不影响本词退出成功证据。交叉格接受提示时，涉及的词仍由现有词级提示集合识别。
- 旧调用或存档缺少提示归属时，依据已有词级错误集合判定；不再使用整局提示数拦截所有词。已有提示操作会将当前词标入错误集合，无法还原的历史提示归属不虚构补齐。
- 两次有间隔的有效成功后退出主动复习；第一次成功延长间隔。普通抽样中的成功同样有效。
- 所有符合档位和间隔要求的复习候选先随机打乱，不再按累计错误次数排序。错误次数保留为历史记录，不参与选词权重。
- 再次填错仍按正常流程重新进入复习、清零退出成功次数并更新到期时间；首次间隔6道其他新题或1天、一次成功后12道或3天、最近3题冷却及每题主动安排与补位合计最多2词的规则继续生效。

本次调整复习退出和候选选择，不改变档位覆盖证据、独立回忆证据及题面难度判断的口径。

没有新增单词近期出现次数上限或失败后暂缓机制。因此反复未成功的词仍会依正常间隔进入候选，但错误累积不再使其更容易被选中；普通随机抽样仍可能重复。

## 验证

新增5项回归测试：

1. 其他词提示或误填时，目标词两次正确后退出。
2. 目标词有两个待填交叉格时，仍能两次成功退出。
3. 目标词自身提示、错误或三字预填时，不误计有效成功。
4. 提示归属缺失但已有词级错误记录时，不连带阻止无错目标词退出。
5. 真实词库、相同候选与随机种子下，仅将某词错误次数从1改为1000，复习词和整题选词结果相同。

修复前，第1、2、4、5项失败，复现了旧行为；修复后定向回归16项通过。最终全量 `flutter test --no-pub` 370项全部通过，`flutter analyze --no-pub` 无问题，`git diff --check`及文档本地引用检查通过。
