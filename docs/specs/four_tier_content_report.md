## 推断参数

仅对未覆盖词使用：1分→入门，2—5分→基础，6—10分→拓展，11—50分→生僻。

这是可解释的首版保守估值，不是监督学习已证明的边界。教材三个档位分布高度重叠，生僻人工样本不足；未强凑80%—90%。旧分不改，后续抽样可覆盖推断。新增词旧分仅为兼容估值，不参与拟合。
