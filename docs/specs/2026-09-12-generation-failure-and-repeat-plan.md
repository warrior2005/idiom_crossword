# 生成失败调查与减少重复感方案

日期：2026-09-12。依据内容版本4、主线策略版本2的当前代码。本次为调查和方案，未修改生产生成算法。相关背景见[重复抽样报告](mainline_repeat_audit.md)。

## 1. 结论与证据边界

复现到的主要失败位于选词／布局阶段：四档配额、陌生词预算及相邻题平滑限制叠加，而生成器采用贪心扩展，没有为后续必选档位预留名额，也没有回退前面已选词的搜索能力。不能简单归因于“总词库不够”或“干扰字不足”。

原抽样12词配置有48/200次生成失败。原工具没有保留这些失败的完整状态，不能追溯宣称48次全部同因，也不能当作线上失败率。本次从空白学习状态固定step30重新累计通关，首次失败在第95次生成；随后保持该玩家状态、关卡号不变进行多次重试和对照。

调查中的诊断副本及合成玩家状态留在`build/`，不写用户真实数据库。随机抽样每次结果会有差异，单一状态的小样本只用于定位和验证方向，不等于修复后的长期成功率。

## 2. 失败现场

第95次生成的状态：

| 项目 | 值 |
|---|---|
| 词数与配额 | 12词：2入门、6基础、3拓展、1生僻 |
| 上一题实际陌生词数 | 6 |
| 本题陌生词预算 | 7 |
| 全部学习记录中熟悉词 | 49 |
| 排除最近3道已通关题后可用熟悉词 | 34：入门12、基础22、拓展0、生僻0 |
| 首次失败路径 | 三轮均由内部生成器返回null；未进入后续候选盘处理 |

本题至少要放3个陌生拓展词和1个陌生生僻词，这已经占4个陌生名额。因此入门与基础的8个位置中，最多只能再有3个陌生词，至少5个必须熟悉，并且能与其他词组成合法交叉题。

34个熟悉词只是数量上可能足够，不代表随意选取就能形成满足全部约束的12词题。当前扩展器可能先填入太多低档陌生词，之后没有名额放必需的高档词，只能整轮重试。反复扩大抽样池也不会自动解决这种选择次序问题。

### 当前代码的具体薄弱点

1. **熟悉词总数代替按档可用量。** `knownCount >= size*3`只决定是否把陌生预算向半题收紧，没有按档位和连通情况预判可行性；近期排除还会让该数量上下波动。
2. **只检查已选词，不检查剩余名额。** `canSelect`检查已选各档数量及陌生数，没有判断剩余必需档位最少还要占多少陌生名额。
3. **搜索缺少回退。** BFS贪心选入后不能撤销前面某个词来重新接其他词，只能换种子／换池再试。
4. **平滑检查可能在完整布局之后拒绝结果。** 本次基线失败主要发生在更早阶段，但这条路径也应单独记录，不要全部归为“布局失败”。
5. **重试没有按失败原因处理。** 三轮扩大候选池最多带来150次内部尝试；约束导致的低命中率不一定因多试而消失。

## 3. 同一状态对照结果

以下均固定同一失败现场，不更新学习记录或历史，只重新生成。除注明的实验变量，沿用相同规则。

| 实验 | 成功次数 | 说明 |
|---|---:|---|
| 原算法，第一批 | 6/10 | 失败请求的三轮均卡在内部生成器 |
| 原算法，第二批 | 16/20 | 同状态也会随机成功；不是数据损坏或必然无解 |
| 每档额外增加1000条候选 | 7/10 | 改善不明确，平均耗时约1.63秒，第一批基线约1.10秒 |
| 提前检查剩余档位所需陌生名额 | 18/20 | 预算仍为7，方向有帮助，但没有完全解决 |
| 陌生预算7→8，保留相邻实际陌生数差≤2等其他规则 | 20/20 | 成功题实际陌生词均为8；待填、配额、词数和候选约束照常检查 |
| 上述名额前瞻＋预算7→8 | 20/20 | 同样通过；仅是单状态验证 |
| 取消陌生上限及对应陌生数平滑检查 | 30/30（两批） | 成功题实际陌生词9—11，明显超过上一题的6，不适合直接上线 |

还试过“只用熟悉词优先选种子”，但现场没有任何到期词，它与原先“到期词∪熟悉词优先”实际上相同，结果差异只能看作随机波动，不能作为有效改进证据。

**可采用的方向是先改搜索，再提供有界、可解释的小步退让；不能直接删掉陌生词限制。** 20/20不代表已经达到发布可靠性要求。

## 4. 降低失败率的实施方案

### 4.1 把可行性检查提前

排除近期词之后，按本题档位配额统计可用词、熟悉词和图连通情况。数量必要条件为：

```text
最少陌生数 = Σ max(0, 本档所需词数 − 本档可用熟悉词数)
```

这只是必要条件，满足仍不保证能合法布局。候选池不能只随机抽够数量，应覆盖各档所需的熟悉词和连接词；不能通过读取“已审核”标记限制选词。

每放入一个词，都重新计算“剩余档位至少需要多少陌生名额”。种子也接受相同检查。优先处理可选空间小的档位及熟悉词缺口，避免低档陌生词提前耗尽名额。

### 4.2 改进搜索，而非无限增加次数

在有限时间内保留少量候选分支，或允许撤回最近少量放置，避免整轮从头开始。搜索应同时考虑配额缺口、熟悉词缺口、连通性及布局合法性。

遇到外层消歧或候选盘检查失败时，尝试保留的其他合格布局。不要把已经计算过的所有候选都丢弃，再盲目扩大词池。为选词、布局、预填、平滑、消歧和候选字不足分别记录失败原因与耗时。

### 4.3 有界回退

建议顺序：

1. 同规模、同配额、同陌生预算下换词／换布局，并优先尝试其他搜索分支。
2. 仍失败时，本次陌生预算最多额外增加1，必须同时满足相邻题实际陌生数差≤2、原待填与候选变化上限；不把生成失败记作玩家能力证据。
3. 该退让需持久记录，设置恢复观察期，避免下一题突然缩回或连续失败推动预算一路上升。不得反复叠加“额外1个”。
4. 如果上述条件无法共同满足，可在普通关卡6—12词范围内减小1词，重新生成合法配额和策略快照；相邻词数、待填及候选量仍受约束。
5. 仍失败就明确返回失败；不通过破坏消歧、干扰下限或冻结规则强行出题。

本次7→8实验说明这种小步回退值得验证，不代表所有玩家都应统一增加陌生词。正式策略参数需要覆盖更多状态后固化。

## 5. 重复感来自哪里

原来“27%—35%半数重合”的口径是与全部已有历史题比较；随着历史增长，这个指标自然上升，不等于短期重复体验。

重新计算原抽样的近期窗口：

| 6词配置 | 与最近20题某题共享至少3词 | 与全部历史某题共享至少3词 |
|---|---:|---:|
| 全入门 | 20/200，10% | 70/200，35% |
| 入门＋基础 | 19/200，9.5% | 54/200，27% |

全入门样本200题里，“心满意足”“运用自如”各出现21次；普通6词样本中“万里无云”“销声匿迹”各出现22次。近期3题排除只能避免紧邻重复，不能阻止少数词每隔几关就回归。

全入门样本最后50题的全新词占答案词总次数约8.7%，普通6词约29%。前者不是单独证明算法出错：池子有限且允许复习，但说明“整题不重复”远不足以代表有新鲜感。

熟悉词／到期词优先、交叉连接偏好和缺少曝光频率惩罚，会使一些词或词对反复组合。不能要求每关永久包含若干从未见过的新词，否则有限低档池耗尽后会被迫升级词汇难度。

## 6. 减少重复感的方案

以下窗口是建议的首版起点，尚未作为产品规则上线。

### 6.1 统一记录实际出现过的新题

增加按时间排序的题目曝光记录，包含实例、词ID集合、组合指纹、出现时间及完成／失败／换题结果。实际展示后才算曝光；同实例恢复或重玩不新增一条“新题”。旧记录可以从现有通关历史保守补齐。

这样去重不再只看到已通关题，也能看到刚失败或刚被换掉的题。当前按关号倒序取通关记录的做法不适合覆盖这些场景。

### 6.2 两层明确去重

- 最近3道实际曝光的新题继续做成语冷却，覆盖失败和换题；恢复原题不参与这条新题规则。
- 最近200道新题不允许完全相同的成语集合再次生成，即使布局、预填或候选顺序不同，也视为同组重出。采用排序后的稳定ID集合指纹检查。

不能把“换了干扰字顺序”当成换了一道题。这两层均应在搜索／候选评价中尽早使用，避免最后一步才反复拒绝。

### 6.3 对局部重复做软约束

对最近20道题评价成语集合重合，普通6词题优先选与任一道近期题最多共享2词的方案；9词优先最多4词，12词优先最多5词。相邻规模不同时按当前题规模计算比例。

初期作为候选排序目标，不立刻叠加成绝对禁令，以免把生成失败率再推高。对近期高频单词、反复一起出现的词对额外降权；在同档、符合熟悉度预算且可连接的候选中挑更少出现的词，不能为了新鲜感偷偷加大生僻比例。

### 6.4 复习时重组搭配

复习保留，但不默认整组回来。到期词分散到不同组合，搭配一些近期20题未出现的词。这些词可以是玩家早已熟悉的词，不必都是第一次出现的陌生词。

建议将每题约四分之一的词作为“近期未出现”选词目标，并把到期复习词分散安排；这仍是软目标，不能突破词汇档位、规模或难度平滑约束。复习时也避免连续复用相同词对和中心词。

## 7. 顺序与验收

先修生成可靠性，再启用整组去重，最后加入频率／重合排序；每一步单独对照，不能一次堆上全部约束。

验证至少包含：

- 本次失败快照及更多失败状态的回归；固定能力、能力渐变、少量熟悉词、熟悉词集中在某一档、近期排除后熟悉词不足等场景。
- 每种代表配置至少1000次连续请求，失败后在同关号重试，分别报告单次请求失败率与重试后仍卡住比例；覆盖跨日复习和提示使用。
- 发布目标：最终生成成功率≥99.9%，所有硬约束违规为0，耗时P50／P95及最大值不恶化到不可接受；具体耗时门槛需真机校准。
- 最近3题冷却及最近200题整组去重无违规；6词关卡“最近20题半数重合率”以从约10%降到3%以下为首轮优化目标，并报告软目标未满足次数和原因。
- 同时观察单词／词对高频集中度、近期未出现词占比和复习完成表现，不能单凭“从未整题重复”判定体验改善。
- 原题恢复、主动提示、失败换题、每日挑战、奖励防重及内容版本迁移回归；新生成策略需统一处理版本识别，不能留下旧代码`strategy == 2`导致新策略漏掉平滑检查。

探测脚本执行完成不代表生成成功率合格。后续验收必须对成功率和硬约束显式断言，不能只打印失败数量后把测试标为通过。

诊断材料：`build/diagnostic_player.db`、`build/generation-diagnostic.json`、`build/generation-reservation-diagnostic.json`、`build/generation-smallstep-diagnostic.json`。这些是合成状态／调试副本；生产代码本轮未改。
