# 固定能力下的主线重复抽样

日期：2026-09-12；内容版本4、策略版本2。使用真实资产和生产生成入口，四种固定策略各连续尝试200道新题；每题模拟通关，正常写入通关历史和学习记录，仅把能力步固定。无固定随机种子，生成器及产品规则未改。

## 定义与结果

- 整组重复：成语集合与此前某一道题完全相同，不考虑顺序。
- 布局重复：成语和各自横纵位置完全相同，不因随机干扰字或预填区别而算新布局。
- 半数重合：与此前任一完整题目共享至少一半成语，不要求相邻；最近3道通关题排除规则照常执行。

| 配置 | 成功生成 | 整组重复 | 布局重复 | 半数重合 | 首次半数重合 |
|---|---:|---:|---:|---:|---|
| 6词，全入门 | 200/200 | 0 | 0 | 70/200（35.0%） | 21道 |
| 6词，4入门＋2基础 | 200/200 | 0 | 0 | 54/200（27.0%） | 18道 |
| 9词，2入门＋6基础＋1拓展 | 200/200 | 0 | 0 | 0/200（0.0%） | 未观察到 |
| 12词，2入门＋6基础＋3拓展＋1生僻 | 152/200 | 0 | 0 | 0/152（0.0%） | 未观察到 |

本轮共尝试800次，成功生成752道题；12词配置有48次返回生成失败，其他配置均成功。成功题的整组和布局重复均未观察到；四种配置也均未发生“只换一个词”的高度重合。每条轨迹只能说明本次前200道题的观察，不能合并当作同一玩家连续800关未重复，更不能将观察频率0%解释为真实概率0%。

6词配置中，首次与历史题共享3词发生在第18／21道模拟题；这是单次轨迹里的首次出现位置，不是固定周期或平均等待关数。单个词重复远比整组重复常见，并受到熟悉词及复习优先影响。

## 适用边界

固定的是能力和规模，学习记忆从空白逐渐累积，不是预置了几千关历史的成熟玩家。假设连续通关、同一次短时间游玩；不覆盖连续失败换题，也不覆盖跨日复习到期或不同提示使用习惯。12词配置的48/200次生成失败（24%）是本轮额外发现，不能将失败请求当作无重复的成功题。模拟遇到失败后继续尝试下一个编号，没有模拟用户在原关号反复重试；这组不足以代表顺利完成200关的真实轨迹，需另行排查生成约束与熟悉词积累的相互影响。

未测到整题重复事件，因此无法可靠估算首次整题重复的平均等待关数；不据此宣称500关、1000关或永久不重复。

目前代码没有整题历史指纹去重，随机生成只降低概率。若要保证最近N道新题不重组，需加入成语组合去重；若要减少玩家的重复感，还需限制近期成语集合重合比例。成语复习本身应继续允许。

复现：`flutter test --no-pub tool/mainline_repeat_audit_test.dart --reporter expanded`。逐题成语、布局、最大重合数及历史重复位置输出至`build/mainline-repeat-audit.json`；再次运行是新的随机样本。本次独立工具测试与工具静态检查通过，没有修改关卡算法。
