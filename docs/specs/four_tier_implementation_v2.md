## 2. 智能适配参数

实现入口：[学习记录](../../lib/src/data/mainline_learning.dart)、[策略](../../lib/src/engine/adaptive_policy.dart)、[生成与冻结](../../lib/src/state/level_generation.dart)。已移除三档设置，旧偏好和科举等级不控制新主线。

| 项目 | 首版实现 |
|---|---|
| 内部策略步 | −5至30，冷启动0；不向玩家显示 |
| 校准规模 | 第1—10关依次2、2、3、3、4、4、5、5、6、6词 |
| 普通规模 | 第11关起`6 + max(step,0) ~/ 5`，实际6—12词；不能用不足6词兜底 |
| 平滑 | 观察值指数平滑，旧趋势权重0.8，新观察0.2；初始趋势0.7 |
| 升降 | 至少5次新终态观察后，趋势≥0.82升一步，≤0.50降一步；变化后重新观察至少5题 |
| 完成证据 | 基准0.92，提示／错误扣权，多字预填再扣0.08；用时不直接惩罚 |
| 未完成证据 | 0.2加已完成词比例×0.65，避免只卡一词就等同整题都不会 |
| 各档表现 | 每题每档一次平滑记录；有5次观察且趋势<0.5记薄弱，生成预填时优先支持；当前涉及档位趋势<0.6时暂缓整体升高 |
| 熟悉词 | 独立完成至少1次，或辅助完成至少3次；仅用于选词支持，不宣称强掌握 |
| 复习 | 辅助完成后1天、独立完成后3天、延迟独立回忆后7天；到期词优先 |
| 低熟悉词预算 | 记忆积累不足时允许全题陌生；足够时逐步趋向半题，按上一题陌生数限制预算每次变动1词 |
| 干扰系数 | `r=0.50…0.80`，每次系数变化0.05；`D=max(4,ceil(A*r))` |
| 最终相邻题约束 | 待填量差≤3、候选总量差≤5、低熟悉词差≤2；正常策略相邻词数差≤1 |

词汇配额、规模、额外待填量和干扰系数的变化安排在不同策略步。连续受挫时保持6词，逐步增进入门词并减少待填。实际生成会校验最终配额与待填预算；消歧增加预填后，重新按实际答案份数计算干扰盘，合法字不足或复杂度越界就重新取词／布局，三轮仍失败则返回生成失败。

普通关卡step0为4入门＋2基础；step7开始可有1拓展；step22开始可有1生僻；step30为2入门＋6基础＋3拓展＋1生僻。生僻出现取决于持续表现，不取决于第几千关。升到step22至少需要110次有效观察，实际可能更久；教材中的难词仍可能在低档出现，不被算法擅自改档。

档内采样覆盖全部数据库词条，不读取审核标记作准入或降权。到期词、个人熟悉度、最近3道已完成题排除及可交叉性影响选词，因此全词库参与不等于均匀抽样。陌生拓展／生僻词生成时至少预填2字，同时每词至少保留1个待填格；更多支持在本题总待填预算内分配。

同一实例的失败、复活、换题不会重复观察。最近40题保留详细记录，另持久保存已观察实例标记，避免明细滚动后重玩旧题再次累计。中断不调整能力。发生失败后复活完成，可以补充该题尚未计入的词级练习，但不再增加第二次能力观察。

## 3. 冻结、界面与兼容

新题冻结成语、网格、预填、候选盘、四档配额、策略步、支持及陌生词预算。候选盘保留重复字的份数，每行最多10字，末行不补齐。消歧沿用字典模式、交叉约束和合法倒装答案规则，最终候选盘再次检查。局内只有玩家主动输入／提示等操作，不自动送字或缩盘。

断点与已通关题都直接恢复原定义，不在重玩时重新消歧；旧题不强套四个干扰字下限。失败后的换题维持原关号、取消／确认与原主题样式，不新增奖励；局内无换题入口。小屏格子小于30逻辑像素时允许手动双指缩放至3倍，这只改变视图。

每日挑战保留现有难度、日期及限时逻辑，选词及题面消歧限定原ID≤29502集合。扩充前后同日、同参数的完整题面编码对照通过。此保证不涵盖任意历史算法版本；新版关联字数据可能改变未保存每日候选盘的干扰字，既有断点保存的候选盘仍原样恢复。

现有分享为图片，没有新增题目导入入口。图片分享回归通过；JSON定义携带新字段，缺省字段继续兼容旧题，超出支持的内容／策略版本拒绝解码，不把未知版本误当已支持题。

经验和奖励公式未修改。不同规模与提示依赖可能改变单位时间经验获取，当前仅验证奖励与防重逻辑，仍需试玩观察成长节奏。

## 5. 剩余外部验收

工程规则和本地兼容验证已完成；以下需要实际设备／玩家，当前未宣称通过：

- 真实iOS旧版本安装升级，检查启动耗时、已有收藏／断点／每日跨日和缩放手感。
