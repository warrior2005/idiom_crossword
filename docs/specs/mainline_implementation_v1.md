# 主线体验改造首版实现与验收

日期：2026-09-09。设计依据：[改造方案](2026-09-09-difficulty-and-level-experience-redesign.md)。

## 已实现

### 内容与兼容（P0）

- `assets/data/mainline_content.json` 是版本化准入源：86 条入门词（基础池子集）、304 条基础词、161 条拓展词。清单是保守初筛，标记 `provisional`，尚未通过目标人群试玩校准；不是教材词频认证或个人掌握度。
- 前20关仅使用入门池，不引入拓展词。后续主线限定基础／拓展池，单关最多1条拓展词，复习关和进一步放松的配置为0；不随关数或科举等级解锁更生僻的词。
- 最终棋盘必须满足拓展上限、基础子图连通、拓展与基础部分交叉；基础起手词给出3字，拓展词至少给出2字。消歧补字后再次检查每条成语仍留有待填字。它是认知可解性的代理检查，不保证每位玩家都能独立过关。
- 有限重试失败后缩小词数，最少2词；不扩大准入边界。最近3关排除仍保留，到期词也不能绕过此排除。
- 已修正旧手工文档第4部分的5条拼音和缩写，同时更新原始数据与资产。旧文档其余计划不执行。
- `data/idiom_ids.json` 固定全部29,502条ID；构建脚本不再根据拼音排序重新分配ID。新增词需先分配未使用ID，停用词保留历史映射。
- 打开用户库时以独立内容版本、ID核验、事务和幂等方式更新拼音。准入标签直接随版本化清单更新，无需在用户库重复保存；原有用户表不覆盖。
- 主线可主动换题，保持关卡号，清理本题作答，不自动通关或发奖励；失败弹窗也提供入口。已完成关卡保留冻结题，不允许通过换题重复领奖。

### 题面与候选盘（P1）

- 轻松配置前5关为2／2／3／3／4词，更多已知字；后续按阶段和偏好控制3—8词。实际无法满足约束时可回退到更少词。
- 三种偏好：轻松入门、日常挑战、成语高手，位于设置页，下一道新题生效。
- 主线候选总数为“实际待填答案份数＋干扰预算”，保留重复字；每行最多10字，允许末行不满，不再固定4行。干扰预算与词数、提示支持相关，轻松题更少。
- 主线干扰字也受入门／基础词所包含的字限制，避免小题混入生僻干扰字。每日挑战和旧题保留原候选规则。
- 窄屏工具栏按可用宽度分配位置，容纳新增换题按钮。
- 题面支持、内容版本、策略版本、题目实例ID随冻结定义保存；候选盘及活跃时长随进行状态保存，旧数据缺省兼容。
- 每日挑战入口保留原生成逻辑。本版不变更其词集合、分数或稳定ID，因此此次拼音修正不改变选词种子顺序；未来词库结构变化仍需另行制定跨版本同题策略。

### 轻量适配与复习（P2 首版）

- 本地记录题目进入、进行／中断、失败、换题、完成，关联实例、内容／策略版本、提示、错误及活跃时长；中断不直接算失败。
- 每5次终态表现才更新一次题面偏移，每次小幅变化；默认轻松玩家也能进一步减少词数、增加已知字并暂停拓展。切换偏好重置观察窗口，科举等级不参与能力估计。
- 本地每词记录出现、练习、辅助完成、独立作答和延迟独立作答。提示、多字预填或未预填交叉字支持下的完成保守记为辅助，不宣称“已掌握”。
- 辅助练习后约1天安排重现；独立作答后约3天，已有隔日独立作答证据后约7天。到期词优先作为生成种子，仍受准入、近期排除、最终配额和布局约束，不能保证每次都选入。
- 练习数据存在现有 settings 表；题目观察保留最近40次，词级汇总保留。没有增加服务器采集或用户级实验分流系统。

## 本轮执行结果

- `flutter analyze --no-pub`：通过，无诊断。
- `flutter test --no-pub`：251项通过、2项失败；失败项均为在基线 `99c595d` 重现的收藏页对齐断言，详见下方说明。本次新增主线、迁移、练习、换题、恢复和候选盘用例通过。
- 抽样报告与真实字体截图工具：2项通过；检查了首关及高手关的候选数量和布局。
- 数据源一致性检查、临时目录全库重建与稳定ID对照、数据库完整性检查通过。
- 本轮未发布应用，未更改真实用户数据库；旧安装内容更新在新版本启动时执行。
