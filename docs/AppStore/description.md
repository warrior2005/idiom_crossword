# App Store 描述（草稿）

## 名称

成语填字

## 副标题

交叉推理，智慧填字

## 描述

成语填字是一款以"交叉推理"为核心的成语填字游戏。一个汉字同时属于横、纵两个成语——它既要是《画蛇添足》的末字，又要是《足智多谋》的首字。多重线索汇聚到唯一答案时的顿悟感，是本作的核心乐趣。

**核心特色**
- 无限关卡：10,000+ 关无限生成，Lv.20 前螺旋难度递增，Lv.20 后「波浪中心 + 三区混排」
- 29,502 条四字成语：难度 1-50 精细分级，干扰字按形近、音近生成，杜绝一眼排除
- 每日挑战：全服同题，2 分钟限时，比拼通关用时
- 科举仕途成长：童生到 Lv.∞ 真龙天子 21 级称号与道具奖励
- 生命值与复活：主线 3 点生命值，失败可用复活卡重整旗鼓
- 通关收藏 + 学习模式：释义、出处、例句随时复习
- 断点续玩：随时退出，随时继续

**适合人群**
- 小学、中学阶段积累成语的学生
- 喜欢字谜与文字游戏的爱好者
- 希望通过游戏保持头脑活跃的中老年朋友
